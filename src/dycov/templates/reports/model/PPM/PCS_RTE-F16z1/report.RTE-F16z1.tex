    \section{Results for PCS: RTE-F16 Zone 1 ({{producer}})}

    The reference curves are the on-site measurements recorded during the commissioning
    tests (DTR Fiche F16, second phase of the open phasor model validation). The model
    runs the tests the producer declared, at the active power levels the fiche requires.

    In this report, \textbf{InternalNode1} denotes the internal connection point of the
    Zone 1 unit model inside the aggregated plant model (the node named \emph{Node1} in
    the DTR). The name \emph{PDR} is reserved for the connection point of the complete
    installation to RTE's grid. All Zone 1 magnitudes (and the corresponding curve signal
    names) refer to InternalNode1.
